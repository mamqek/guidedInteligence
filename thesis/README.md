# Thesis workspace

This directory is the repository-local home for thesis source material, planning, and the university LaTeX template.

## Authoritative university sources

- `sources/master-project-student-manual.pdf` - January 2026 Master Project Software Engineering student manual.
- `sources/assessment-rubric.pdf` - assessment rubric for the research, thesis, and defence.
- `sources/msc-se-master-thesis-template.zip` - original downloaded template archive.
- `template/` - extracted working copy of the university LaTeX template.

## Project planning sources

- `sources/thesis-plan.md` - the 26 August 2026 thesis outline supplied by the student.
- `planning/outline-review.md` - a planning review of that outline. This is working guidance, not thesis prose.

## Manuscript workspace

- `manuscript/` - chapter-by-chapter Markdown workspace that will eventually contain the full student-authored thesis.
- `manuscript/04-research-method.md` - current Research Method evidence scaffold and, later, the student's chapter prose.

## Use

Consult the manual, rubric, and template before changing the thesis structure or formatting. Treat the PDFs and original template archive as reference copies. The student manual says that structural deviations are allowed when appropriate to the research, but should be discussed with the academic supervisor.

The university material also requires the submitted thesis to be written by the student and contains rules about generative-AI use. Material in `planning/` is therefore for planning and critique only; it must not be copied into the submitted thesis as if it were student-authored prose.
