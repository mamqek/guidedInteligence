# Conclusion

Repository questions rarely identify the source that answers them. Retrieval must first locate plausible files, then preserve the particular ranges needed to support an explanation within a bounded context. This thesis addresses that problem through Guided Intelligence, a repository-assistance artifact whose native Workspace mode separates retrieval, structural resolution, semantic qualification, bounded adaptive exploration, and final evidence selection. The evaluation compares four Workspace configurations and Codex across 35 CodeRepoQA-derived testcases and 700 accepted runs. In addition to file-ranking measures, a corpus-wide reference evaluates the joint survival of 78 exact pre-resolution source units.

The first research question asks how retrieved source can become an inspectable evidence set. Guided Intelligence gives source observations stable identities, retains their discovery and qualification history, separates navigation leads from factual evidence, and records final selection independently from retrieval. The resulting trace can show whether required source remains available and locate its first recorded unavailability boundary. This capability makes evidence construction auditable, but it does not make semantic decisions deterministic or prove that a response model understands the selected source.

The second research question concerns CodeGraph and bounded adaptive exploration. Adaptive exploration provides modest improvements in file ranking and required-source survival, while accounting for most of Workspace's additional model-token cost. CodeGraph has mixed aggregate ranking effects: it slightly improves recall and required-unit survival but does not consistently improve the earliest ranks. Its clearest contribution is conditional, through enclosing-owner identity, exact navigation, and preservation of source that flat ranges represent poorly. Neither capability guarantees complete multi-file evidence, and connectedness cannot be isolated from the number of required units and files.

The third research question compares Full Workspace with Codex as complete retrieval systems. Codex achieves stronger file recall and required-evidence completeness and returns broader evidence sets. Full Workspace more often places an implementation file first, uses substantially fewer model tokens, and exposes its internal evidence lifecycle. These differences do not isolate agentic navigation as the cause because the systems also differ in search, stopping, context construction, and consolidation. They establish a trade-off between broader recovery and the native pipeline's prioritisation, cost, and observability.

The thesis contributes the Guided Intelligence artifact, a controlled repository-evidence lifecycle, bounded adaptive exploration, and an evaluation that combines file ranking with exact-source survival and stage-aware analysis. The complete run appendix makes every required unit and all 700 judgements inspectable. The findings show why file localisation alone is insufficient: a selected file can omit its responsible source, individually retrievable units may never survive together, and relevant material can become unavailable at several later boundaries.

The exact-source results make this distinction concrete. Full Workspace contains every required unit in 23 of 140 runs, while Codex does so in 55. Codex therefore remains incomplete in 85 runs despite labelling every result `strong` and sufficient. Full Workspace completes no run whose required reference spans three or more files, and even Codex completes no five- or six-file case. These outcomes identify joint evidence assembly, rather than initial localisation alone, as a central remaining limitation. They also show why evidence requirements defined outside the evaluated system are necessary when assessing that system's own completeness judgement.

These conclusions remain bounded. The required-evidence reference is researcher-constructed and includes judgment-sensitive scope choices without independent annotator agreement. Final-selection omissions are directly recorded, whereas earlier unavailability boundaries are inferred from successive stage observations. Codex provides no comparable internal trace. The corpus covers three repositories, static-analysis limitations remain, and the study does not evaluate generated-answer correctness or learning outcomes. Exact required-source availability is therefore stronger evidence than file overlap, but it is not proof of complete causal understanding.

Future work should validate evidence requirements and response understanding independently, improve preservation and selection for multi-file evidence, and evaluate the system with developers or learners. The principal conclusion is that trustworthy repository assistance should not reduce understanding to finding plausible files. It should preserve how source becomes evidence, expose what remains unresolved, and qualify its output when the available evidence is incomplete. An inspectable retrieval process cannot guarantee a correct explanation, but it provides stronger grounds for evaluating and responsibly producing one.
